# Pixel Kingdom

모바일 아이소메트릭 마을 건설 게임 웹 체험판입니다.

## 플레이

GitHub Pages 설정 후 `https://plaming2.github.io/pixelkingdom/`에서 실행합니다.

- 아이폰 Safari 지원을 목표로 한 단일 HTML5 게임
- 터치 드래그, 건물 건설, 도로 및 간이 생산·운송, 브라우저 로컬 저장

## 배포

GitHub 저장소 Settings → Pages → Deploy from a branch → main / (root).
공개 접근을 위해 저장소의 visibility와 GitHub Pages 사용 조건을 확인해야 합니다.

## 상태

프로토타입. 모바일 실기기 동작과 생산·물류·저장 기능의 완전한 검증은 아직 끝나지 않았습니다.
